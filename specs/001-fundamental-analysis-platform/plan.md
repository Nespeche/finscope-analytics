## Arquitectura objetivo

Aplicación Svelte 5 + TypeScript estricto, Vite, Vitest, Playwright, Web Worker tipado, IndexedDB transaccional y gateway Cloudflare Worker SEC read-only. Los snapshots fundamentales son inmutables; el overlay de precio es opcional, versionado e independiente. Todas las fórmulas usan `decimal.js`, `ROUND_HALF_EVEN` y `DecimalString` canónico.

La composición ejecutable tiene raíces explícitas: `src/main.ts` → `App.svelte` → `app/composition.ts`; `orchestrator.worker.ts` → `operation-registry.ts`; y `workers/sec-gateway/src/index.ts` → tabla de rutas. Crear un módulo sin conectarlo a su raíz no satisface `Done when`.

La validación de JSON Schema usa `Ajv2020` conforme a `contracts/schema-validation-runtime.md`: sin coerción, defaults ni eliminación de propiedades; formatos determinísticos registrados por el proyecto; `strictRequired=false` y `strictTypes=false` son excepciones de compilación documentadas para schemas compuestos y no relajan la validación de instancias.

La estructura es una SPA Svelte 5, no SvelteKit. El gateway usa APIs nativas de Workers, sin Hono u otro framework. La visualización usa HTML/SVG accesible con alternativa tabular, sin biblioteca gráfica obligatoria. `ajv` es la única dependencia de validación JSON Schema Draft 2020-12; `@axe-core/playwright` complementa Playwright pero no sustituye la revisión manual WCAG. IndexedDB se usa mediante APIs nativas para evitar una capa ORM adicional. La migración D1 es necesaria únicamente para el catálogo/versionado público compacto y no crea almacenamiento personal server-side.

## Flujos obligatorios

### Flujo fundamental

1. Resolver identidad por CIK sin selección heurística.
2. Verificar consentimiento y novedad mediante Submissions.
3. Adquirir Company Facts y, solo cuando corresponde, Company Concept exacto.
4. Validar mappings XBRL, perfiles, unidades, período, scope y precedencia.
5. Normalizar facts y calidad sin inferencias silenciosas.
6. Evaluar fórmulas según precedencia normativa y decimal.js.
7. Calcular métricas y reglas solo con inputs/quality gates válidos.
8. Proyectar fingerprints fundamentales sin reloj ni precio.
9. Persistir candidato completo y publicar pointer mediante compare-and-swap.
10. Conservar snapshot previo ante fallo o cancelación.

### Flujo de precio

1. Validar CSV completo antes de persistir.
2. Crear overlay inmutable con nueva versión.
3. Calcular métricas históricas descriptivas y fingerprints de precio.
4. Actualizar únicamente el pointer de precio.
5. No modificar bundle, snapshot, análisis ni fingerprints fundamentales.

## Actualización, seguridad y persistencia

- Actualización foreground al abrir/reanudar y refresco manual; nunca scheduler con la app cerrada.
- Cache `fresh < 6 h`, `stale_revalidatable 6 h–<7 d`, `expired ≥7 d`.
- SEC: 14 llamadas máximas, concurrencia 1, tres intentos, backoff 1/2/4 s, timeout 20 s/120 s y 64 MiB.
- CSV: 5 MiB, 50.000 filas, 8 columnas, UTF-8, sin fórmulas ni escrituras parciales.
- IndexedDB opt-in, exportación/restauración con preview, hashes y transacción atómica.

## Test architecture and performance budgets v0.19.3

Vitest ejecutará pruebas unitarias, de integración, contract tests, schemas y fixtures positivos y negative. Playwright ejecutará end-to-end sobre flujos de adquisición, import, restore, cancelación, accesibilidad y degradación por cuota. Cada suite usa reloj inyectado, fixtures congelados y semillas determinísticas.

Los performance budgets se verifican por escenario: UI responsiva con cómputo financiero fuera del hilo principal, mensajes Web Worker cancelables, importación incremental, memoria acotada y Worker Cloudflare p95 ≤ 4 ms de CPU. Ningún test live SEC es gate de release.

## Cloudflare Free execution envelope v0.19.3

`governance/cloudflare-free-budget.json` es autoridad ejecutable. Pages aloja activos; Workers actúa como gateway de streaming con una subrequest; D1 guarda solo catálogo/versionado compacto. KV, R2, Queues, Durable Objects, Pages Functions y Cron no se usan. Al alcanzar límites, la aplicación conserva snapshot local, desactiva refresh no esencial y nunca migra silenciosamente a un plan pago.
