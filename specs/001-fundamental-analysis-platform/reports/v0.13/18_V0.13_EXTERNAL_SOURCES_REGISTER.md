# Registro de fuentes externas v0.13

**Fecha de consulta:** 2026-07-20. Solo se consultaron fuentes oficiales/primarias permitidas.

| Organismo | Título | URL | Afirmación verificada | Impacto | Decisión |
| --- | --- | --- | --- | --- | --- |
| IETF / RFC Editor | RFC 9457 — Problem Details for HTTP APIs | https://www.rfc-editor.org/rfc/rfc9457 | El status del body es advisory, pero el generador debe usar el mismo status HTTP; type identifica el tipo de problema. | Sustenta V13-B05 y el control de status/cuerpo. | Mantener code como extensión, pero cerrar la correspondencia por respuesta HTTP. |
| OpenAPI Initiative | OpenAPI Specification v3.1.1 | https://spec.openapis.org/oas/v3.1.1.html | OAS 3.1.1 usa Schema Objects compatibles con el dialecto JSON Schema definido. | Base del parseo, $ref y uniones/const. | La versión 3.1.1 del baseline es válida; el problema es su modelado, no su número. |
| JSON Schema | Draft 2020-12 | https://json-schema.org/draft/2020-12 | Semántica de oneOf, const, unevaluatedProperties y validación estructural. | Base de ejemplos conceptuales válidos/inválidos. | Usar restricciones condicionales para cerrar variantes. |
| U.S. SEC | Developer Resources / Fair Access | https://www.sec.gov/about/developer-resources | Guía vigente de no más de 10 requests/segundo y uso eficiente. | Verifica límite externo; no sustituye el presupuesto interno de 10 llamadas por análisis. | Conservar presupuesto interno conservador y trazable. |
| U.S. SEC | EDGAR Application Programming Interfaces | https://www.sec.gov/search-filings/edgar-application-programming-interfaces | Submissions y companyfacts están disponibles como APIs JSON oficiales. | Confirma fuentes SEC primarias admitidas. | Mantener SEC como fuente principal y Company Concept selectivo. |
| W3C | Web Content Accessibility Guidelines 2.2 | https://www.w3.org/TR/WCAG22/ | Criterios de éxito testables y no específicos de tecnología. | Sustenta necesidad de criterios medibles por interacción. | Descomponer AC-124/125 en criterios observables. |
| Cloudflare | D1 limits | https://developers.cloudflare.com/d1/platform/limits/ | Free: 500 MB por DB, 5 GB por cuenta, 50 queries por invocación. | Verifica que la arquitectura debe seguir siendo compacta. | No se detecta conflicto directo; los contratos de publicación siguen incompletos. |
| Cloudflare | Workers limits | https://developers.cloudflare.com/workers/platform/limits/ | Free: 100.000 requests/día, 10 ms CPU por request, 50 subrequests y 5 Cron Triggers. | Confirma necesidad de orquestación ligera/incremental. | No usar Worker Free para procesamiento pesado no acotado. |
| GitHub | GitHub Actions billing | https://docs.github.com/en/billing/concepts/product-billing/github-actions | Repos públicos con runners estándar son gratuitos; privados tienen cuota según plan. | Valida que “CI gratuito” depende de visibilidad/plan y cuota. | Documentar supuesto operativo antes de implementación pública. |
| NYSE | Holidays & Trading Hours | https://www.nyse.com/markets/hours-calendars | Calendario oficial, feriados y cierres anticipados; 2026-11-27 cierre 13:00 ET. | Confirma el ejemplo, pero revela que el baseline no incorpora el calendario materializado. | Incluir artefacto versionado, no depender de consulta ad hoc en runtime. |
| Nasdaq | US Stock Market Holiday Schedule | https://www.nasdaq.com/market-activity/stock-market-holiday-schedule | Calendario oficial y cierres anticipados 2026. | Misma conclusión para XNAS. | Materializar y versionar. |
| ISO 20022 / ISO 10383 | Market Identifier Codes | https://www.iso20022.org/market-identifier-codes | MIC identifica mercados y dispone lista oficial versionada. | Sustenta MIC explícito como identidad de venue. | Registrar versión/fuente/revisión por entrada. |
| IANA | Time Zone Database | https://www.iana.org/time-zones | Base oficial de identificadores/reglas de zonas horarias. | Sustenta zona IANA del mercado. | Registrar versión de tzdb o política de actualización. |

Las fuentes externas no se usaron para “reparar” la documentación; solo para verificar estándares, límites y ejemplos oficiales.
