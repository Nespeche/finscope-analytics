## NF-001 — Oracle AC-071 (MINOR) — CERRADO

**Archivo:** `definitions/acceptance-criteria-catalog.json`, criterio AC-071

**Problema original:** Oracle `"control aria-busy/disabled as appropriate"` — "as appropriate" es no-determinista.

**Corrección aplicada:**
```
"oracle": "aria-busy=true on the refresh control while pipeline is in checking|acquiring|normalizing|analyzing;
           aria-disabled=true when pipeline is in failed|cancelled state;
           both attributes absent when pipeline is in idle|ready|partial"
```

**Verificación:** el nuevo oracle es exactamente verificable por estado de pipeline. Se eliminó toda expresión no-determinista. El `oracleKind: single_exact_oracle` es ahora correcto.

## NF-002 — otherApprovedInterestBearingBorrowings sin mapeo XBRL (MAJOR) — CERRADO

**Archivo:** `definitions/xbrl-mapping-catalog.json`, sección `debtPolicy`

**Problema original:** El concepto `otherApprovedInterestBearingBorrowings` aparecía en `debtPolicy.buckets` y en `metric-catalog.json FND_BORROWINGS_DEBT.optionalInputIds` sin ninguna entrada de mapeo en el catálogo, creando una referencia sin resolución documentada.

**Corrección aplicada:** Se añadió `debtPolicy.knownAbsentConcepts` con una entrada `known_absent_intent` que:
- Explica por qué no existe un tag US-GAAP canónico para este bucket
- Documenta el impacto: `FND_BORROWINGS_DEBT` puede llegar a estado `partial` para issuers con deuda no-estándar
- Confirma que la ausencia es intencional y compatible con el `debtPolicy` existente

**Verificación:** La inconsistencia entre catálogo de métricas y catálogo XBRL está ahora explícitamente documentada como diseño intencional, no como omisión.

---

## NF-003 — Librería de aritmética decimal no especificada (MAJOR) — CERRADO

**Archivos:** `spec.md`, `governance/authority-crosswalk.json`

**Problema original:** La aritmética decimal (scale=12, ROUND_HALF_EVEN) estaba completamente especificada en comportamiento pero sin que ningún documento nombrara la librería JavaScript a usar. Ninguna tarea de cómputo de métricas podía implementarse sin esta decisión.

**Corrección aplicada:**
1. Nuevo artefacto: `decisions/decimal-library.md` — declara `decimal.js` v10+, MIT, con justificación técnica y reglas de uso
2. `spec.md` — nueva sección "Decisiones de tecnología" referencia `decisions/decimal-library.md`
3. `governance/authority-crosswalk.json` — nuevo dominio AUTH-026 `decimal_arithmetic`, primaryAuthority = `decisions/decimal-library.md`

**Verificación:** Todo código de métricas puede ahora referir al artefacto normativo `decisions/decimal-library.md` para la elección de librería.
