# Informe de Problem Details — v0.12

Se adopta RFC 9457. `BaseProblem` contiene los cinco campos estándar y extensiones de operación, estados afectados, recovery, retry, capacidades, claves de UI/accesibilidad y correlación.

`ProblemDetails` es `oneOf` con discriminator `code`. Las 17 variantes fijan mediante `const`: código, HTTP status, operationState, affected coverage/metrics, recoveryActions, retryability, preservedCapabilities, blockedCapabilities, userMessageKey y accessibilityAnnouncementKey. `unevaluatedProperties=false` cierra extensiones no autorizadas.

Los mensajes humanos no son autoridad. `code` gobierna máquina, las claves gobiernan UI localizada y `detail` solo informa. Un error operativo no transforma silenciosamente freshness, compatibilidad o MetricResult.
