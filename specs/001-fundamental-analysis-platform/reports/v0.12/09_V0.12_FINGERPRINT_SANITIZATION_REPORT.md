# Informe de fingerprints y sanitización — v0.12

## Separación de autoridades

- `canonicalSeriesFingerprint`: obligatorio, financiero, reproducible, invalida análisis y snapshots.
- `sourceEvidenceFingerprint`: opcional, evidencia técnica no financiera; su estado es `computed|not_permitted|not_available|not_applicable`.

## Proyección canónica

Incluye contrato, identidad, MIC, moneda, ventanas solicitada/efectiva, observaciones normalizadas, ajuste, cobertura corporativa, warnings/limitaciones canónicos, versión de adaptador y normalización. Excluye raw, credenciales, URL completa, headers, request IDs, timestamps operativos, mensajes humanos, cuota y evidencia.

## ProviderEvidenceProjection

Allowlist: identidad técnica, solicitud semántica, HTTP status, moneda, zona declarada, ajuste, última actualización, cantidad, observaciones mínimas usadas y códigos canónicos. Todo lo demás se elimina.

## Canonicalización

UTF-8; JSON canónico; propiedades determinísticas; fechas `YYYY-MM-DD`; MIC/moneda uppercase; decimales sin exponentes; `-0→0`; rechazo NaN/Infinity; arrays normativamente ordenados; SHA-256. `null` y ausencia no son equivalentes.

## Frontera

El raw solo existe en el adaptador temporal. No atraviesa pipeline, almacenamiento, snapshots, UI ni Problem Details.
