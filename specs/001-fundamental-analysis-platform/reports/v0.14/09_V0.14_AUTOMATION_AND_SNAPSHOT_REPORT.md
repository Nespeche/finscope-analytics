# Automatización y snapshots v0.14

## Modelo activo

- Adquisición por selección de emisor, refresh manual o refresh al abrir/reanudar con consentimiento.
- Web Worker normaliza y analiza.
- Matriz incremental delimita artefactos afectados.
- `PersonalAnalysisSnapshot` es inmutable.
- Transacción IndexedDB: candidato → índice de evidencia → pointer activo → commit.
- Fallo/cancelación conserva el pointer anterior.

## Flags

- `centralMarketUpdateEnabled=false`
- `marketProviderAdaptersEnabled=false`
- `publicSnapshotAutomationEnabled=false`

Todos los flujos ordinarios y recuperaciones operan desde UI; no se requiere terminal.
