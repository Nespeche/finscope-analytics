# Registro de fuentes externas oficiales v0.14

**Fecha de consulta:** 2026-07-20. Solo se usaron fuentes oficiales/primarias.

| Organismo | Documento | Fecha/versión consultada | Afirmación aplicada | Impacto/decisión |
|---|---|---|---|---|
| U.S. SEC | EDGAR Application Programming Interfaces | consulta 2026-07-20 | Submissions, Company Facts y Company Concept son APIs oficiales sin autenticación; Company Facts agrega facts por compañía. | SEC-first; Company Facts principal. |
| U.S. SEC | Internet Security Policy / Fair Access | consulta 2026-07-20 | Automatización debe respetar fair access; la SEC publica un máximo de 10 solicitudes por segundo. | Gateway con identificación, caché, budget y backoff. |
| XBRL International | XBRL Dimensions 1.0 | Recommendation | Los contextos/dimensiones afectan semántica y comparabilidad de facts. | Scope/dimensionalidad compatibles obligatorios. |
| IETF | RFC 8785 — JSON Canonicalization Scheme | 2020 | JCS define representación canónica de JSON para hashing/firma. | Fingerprints JCS + SHA-256. |
| IETF | RFC 9457 — Problem Details for HTTP APIs | 2023 | Estructura estándar de problemas HTTP y extensiones. | 12 variantes tipadas de error. |
| OpenAPI Initiative | OpenAPI Specification 3.1.1 | 2024 | OAS 3.1.1 y JSON Schema dialect. | Contrato OpenAPI activo. |
| JSON Schema | Draft 2020-12 Core | 2022 publication | Vocabulario/core del dialecto. | Schemas cerrados y discriminated unions. |
| W3C | Web Content Accessibility Guidelines (WCAG) 2.2 | Recommendation 2023 | Criterios de accesibilidad aplicables a teclado, foco, labels, status y errores. | Criterios separados de accesibilidad. |
| W3C | Indexed Database API 3.0 | Living standard | Transacciones y object stores soportan persistencia local estructurada. | Publicación atómica de snapshots locales. |
| Cloudflare | Workers limits | consulta 2026-07-20 | Plan Free con límites de solicitudes/subrequests/CPU que requieren gateway liviano. | Sin procesamiento intensivo central. |
| Cloudflare | D1 limits | actualización oficial consultada 2026-07-20 | D1 posee límites de tamaño/queries; no es repositorio de snapshots personales/raw masivos. | D1 limitado a metadata/catálogos/versiones/mappings/políticas. |
| Cloudflare | Pages limits | actualización oficial consultada 2026-07-20 | Límites de builds, archivos y assets. | Artefacto frontend compacto futuro. |
| Twelve Data | Terms of Service | consulta 2026-07-20 | Uso/licencia/redistribución requiere cumplimiento específico. | Provider diferido; sin adapter ni key en MVP. |
| Alpha Vantage | Terms of Service | consulta 2026-07-20 | Uso de datos sujeto a términos/licencias aplicables. | Provider diferido; sin adapter ni key en MVP. |
