# OpenAPI y Problem Details

OpenAPI 3.1.1 mantiene 11 operaciones read-only. Cada response de error deriva de `operationMatrix`; 409 y 422 fueron retirados. El catálogo activo tiene 6 variantes generales y 4 resource-not-found especializadas. Campos normativos son const-bound, arrays de capabilities son específicos y issues locales quedan fuera de HTTP.
