# Autoridades machine-readable

La autoridad primaria migró de tablas interpretables a catálogos JSON y JSON Schema 2020-12 para perfiles, mappings, métricas, calidad, reglas, estados, problemas, issues, aceptación, fingerprints, SEC y storage. `authority-crosswalk.json` registra 25 dominios y consumers inversos. Markdown queda como vista humana, no como segundo oráculo.
