# Matriz proveedor/raw → contrato canónico — v0.10

| Fuente/raw | Campo externo típico | Campo canónico | Transformación/validación | Destino raw |
|---|---|---|---|---|
| API autorizada | timestamp/date | observation.date | fecha de sesión, ISO date, ascendente | eliminado al normalizar |
| API autorizada | open/high/low/close | observation.* | decimal; close>0; OHLC invariant | eliminado |
| API autorizada | adjusted close | adjustedClose | solo si semántica documentada | eliminado |
| API autorizada | volume | volume | >=0 y unidad conocida; de lo contrario null+warning | eliminado |
| API autorizada | symbol/exchange/currency | identity/series | validar contra request/catálogo; no confiar silenciosamente | eliminado |
| API autorizada | adjustment metadata | adjustmentStatus/source/coverage | no inferir; unknown cuando no verificable | eliminado |
| API autorizada | source metadata | MarketSeriesTrace | sanitizar y eliminar secretos | eliminado |
| CSV | columnas mapeadas | MarketObservation | mapping explícito, validación atómica | archivo no sale del navegador |
| Entrada manual | lastClose/resumen | ManualMarketSummary | no inventa observaciones ni MarketSeries | input de sesión |

## Adaptadores latentes

Twelve Data y Alpha Vantage no tienen mapping ejecutable mientras `enabled=false`; sus nombres externos pueden documentarse solo como evidencia, nunca consumirse downstream.

## Regla de frontera

Ningún raw, alias, mensaje de proveedor o credencial puede llegar a pipeline, UI, IndexedDB, D1, Cache API, exportación o fingerprint canónico.
