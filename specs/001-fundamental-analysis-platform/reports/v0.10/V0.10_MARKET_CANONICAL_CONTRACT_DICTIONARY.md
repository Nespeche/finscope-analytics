# Diccionario del contrato canónico de mercado — v0.10

**Autoridad:** `contracts/canonical-market-contract.md`. Esta matriz es evidencia de revisión, no un segundo contrato.

| Objeto | Propiedades canónicas | Regla crítica |
|---|---|---|
| `DepositaryRatio` | receiptUnits, underlyingShareUnits, sourceReference, verifiedAsOfDate | ratio >0 y verificable; sin FX implícito |
| `InstrumentIdentity` | schemaVersion, instrumentId, issuerId, cik, issuerName, listingId, ticker, exchange, mic, shareClassId, shareClassLabel, economicRightsClassId, quoteCurrency, instrumentType, underlyingInstrumentId, depositaryRatio, identityResolutionState, limitations | todas requeridas; nullable explícito; MIC null fingerprinted |
| `MarketObservation` | date, open, high, low, close, adjustedClose, volume, sourceRecordId, qualityFlags | close>0; OHLC coherente; moneda no duplicada |
| `RequestedMarketWindow` | mode, startDate, endDate, outputSize | variantes exclusivas date_range/last_n; default 100 materializado |
| `EffectiveMarketWindow` | startDate, endDate, observationCount | count=usedCount=observations.length |
| `MarketQualityFlag` | seis códigos cerrados de ausencia/normalización por observación | array requerido, ordenado y sin duplicados |
| `MarketWarningCode` | once códigos cerrados de cobertura, límites, deduplicación, ajuste y metadata | no admite texto/código de proveedor |
| `MarketWarning` | code, message, affectedFields | code/fields fingerprinted; message no |
| `MarketAcquisitionParameters` | interval=`daily`, adjustmentPreference | objeto cerrado; sin credenciales ni aliases |
| `MarketSeriesTrace` | sourceKind, providerId, policyVersion, evidenceReference, acquiredAt, parameters, requested/effectiveWindow, counts, warnings, limitations, payloadFingerprint, stopReason | credenciales prohibidas; counts reconciliados |
| `MarketSeries` | schemaVersion, seriesId, instrumentIdentity, interval, currency, marketCalendar, timeZone, asOfDate, observations, adjustmentStatus, adjustmentSource, corporateActionCoverage, coverageState, freshnessState, truncated, trace, fingerprint | seriesId=fingerprint; coverage solo complete/partial; cancelación/rechazo no emite serie |

## Ausencia y null

Todas las propiedades canónicas se serializan. `null` representa desconocido permitido; omisión, cadena vacía, cero, NaN y sentinels externos están prohibidos.

## Fingerprint

SHA-256 sobre JSON canónico con claves ordenadas, fechas normalizadas, null explícito y arrays normativos. Excluye IDs derivados, acquiredAt, sourceRecordId y textos de mensaje. Incluye MIC null/valor, warnings codes, limitaciones, ventanas, parámetros y datos.
